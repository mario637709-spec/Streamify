# Privacy Policy — GTA Tadka Uploader

Last updated: 25 November 2026

GTA Tadka Uploader is a private, single-user automation tool. It is used by the owner of the YouTube channel **GTA Tadka** (@GTATadkaHindi) to upload the owner's own videos to that channel through the official YouTube API Services. It is not a public service and is not offered to any other users.

## What data the app accesses

With the channel owner's explicit consent (Google OAuth, scope `https://www.googleapis.com/auth/youtube.upload`), the app receives an authorization token that allows it to upload video files to the owner's own YouTube channel and to set basic video details (title, description, privacy status) for those uploads. The app does not read, collect, or store any other Google account data, and it does not access data of any other person.

## What data is stored

The OAuth refresh token is stored only on the owner's own private computer, in a permission-restricted file, solely so that scheduled uploads can run without manual sign-in each time. Video files, titles and descriptions processed by the app are the owner's own content. No data is sold, rented, shared, or transferred to any third party. No analytics, advertising, or tracking of any kind is used.

## How access can be revoked

The owner can revoke the app's access at any time from the Google Account page (myaccount.google.com → Security → Third-party access), which immediately stops the app from uploading.

## YouTube API Services

This app uses YouTube API Services. By using it, the owner agrees to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's privacy practices are described in the [Google Privacy Policy](https://policies.google.com/privacy).
